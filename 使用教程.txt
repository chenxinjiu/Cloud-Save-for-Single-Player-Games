========================================================================
 gssync 云存档同步 · 使用教程（中文）
 版本 v0.6.0
========================================================================

【一、这是什么】
gssync 是一个 Windows 上的单机游戏存档同步工具。它把你的游戏存档放进
你自己的 GitHub 私有仓库，从而在多台电脑之间对齐存档：
  · 在这台电脑玩完      → 点【上传】，存档进云端；
  · 换一台电脑继续玩    → 点【拉取】，存档回到本地。
它不依赖任何第三方网盘或服务器，只用你自己的 GitHub 账号；仓库是私有的，
别人看不到。支持任意单机游戏；对《远行星号》有内置规则（存档 + MOD +
启动参数一起同步）。

【二、运行要求】
  · 系统：Windows 10 / 11（64 位）
  · 一个 GitHub 账号（免费即可）
  · 一个 GitHub Token（只需 repo 权限，申请方法见下）
  · 游戏装在本地（存档能在本地找到）

【三、怎么拿到程序 / 怎么发给别人】
程序就是一个"绿色单文件"，双击即用，无需安装，也无需装 Go / Java / 任何运行库。
发行目录里有两个 exe：
  · gssync-gui.exe   ← 有窗口界面，给普通用户用（推荐，双击就打开窗口）
  · gssync.exe       ← 命令行版（进阶用户；两者功能相同）
把 exe 发给别人，最简单的方式：
  1) 直接把 gssync-gui.exe 发过去（微信 / QQ / 网盘 / U盘都可以）；
  2) 或者把两个 exe 一起放进一个文件夹压缩后发过去；
  3) 或者把对方加为这个 GitHub 私有仓库的协作者，让他自己下载。
注意：
  · exe 没有数字签名，Windows 首次运行可能弹"Windows 已保护你的电脑"。
    点【更多信息】→【仍要运行】即可。杀毒软件若误报，请加白名单。
  · 普通用户只需要一个文件：gssync-gui.exe（gssync.exe 可给可不给）。

【四、首次配置（在窗口里点几下就行）】
双击 gssync-gui.exe，窗口会打开（首次使用会自动停在【设置】页）。按顺序填写：
  1) GitHub 仓库：填你自己的仓库。可以只填"仓库名"（如 starsector-cloud-saves），
     保存时会自动补成"账号/仓库名"；也可以直接填"账号/仓库名"。
  2) Token：到下面的链接生成，勾选 repo 权限，复制粘贴进来：
       https://github.com/settings/tokens/new?scopes=repo&description=gssync
     （Token 只保存在你电脑的 Windows 凭据管理器里，不会写进任何明文文件。）
  3) 游戏类型：
       starsector = 远行星号（内置规则：存档 + MOD + vmparams）
       generic    = 通用（其它单机游戏，需自己指定存档目录）
  4) 游戏根目录：如 E:\yxx\Starsector（远行星号填游戏根目录即可）。
  5) 存档目录：点【浏览…】选存档所在文件夹；远行星号留空 = 自动用
     根目录\saves。
  6) 识别模式 / 匹配规则 / 进程名：一般不用改。
       · 远行星号：保持默认。
       · 通用游戏：识别模式按该游戏的存档形式选
         （subdir = 每个子文件夹一个存档；file = 每个文件一个存档；
          single = 整个存档目录算一个存档）；
         匹配规则填文件名通配（如 *.sav，逗号分隔；留空 = 全部）；
         进程名填游戏的 exe 名（如 game.exe），用于判断"游戏是否正在运行"。
  7) 设备名：区分不同电脑，默认就是本机名，一般不用动。
然后：先点【测试连接】确认 Token 和仓库没问题，再点【保存设置】。
  · 若仓库还不存在，勾选【仓库不存在时自动创建私有仓库】再保存，会自动建好。

【五、日常使用（就在【同步】页）】
  · 【上传存档】（以本机为准）：把当前这台电脑的存档传到云端。玩完存一次即可。
  · 【拉取存档】（覆盖本机）：把云端的存档下载并覆盖本机。
        重要：拉取前请先退出游戏！程序检测到游戏在运行会拒绝拉取，防止坏档。
  · 【查看状态】：看本机与云端哪些存档不一样、哪边更新。
  · 【上传MOD / 拉取MOD】（远行星号）：把 mod 也同步到另一台电脑，免去手动拷贝。

【六、多台电脑怎么用】
  · 存档互通的前提：多台电脑用同一个仓库 + 同一个 Token（同一 GitHub 账号）。
  · 每台电脑的"设备名"可以不同（用于区分），不改也可以。
  · 典型流程：A 电脑玩完点【上传】→ B 电脑点【拉取】→ 继续玩 → B 点【上传】……
  · 如果是把工具送给"另一个人"，建议让对方用他自己的 GitHub 账号和仓库，
    各用各的，互不影响。

【七、自动更新】
每次打开 gssync-gui.exe，它会检查云端有没有新版本，有就自动下载替换：
  · 更新后需关闭窗口再打开才生效。
  · 需要能访问"应用仓库"（本程序发布所在的仓库）。
  · 检查失败只会在状态栏提示一行，不影响任何功能使用。

【八、数据都存在哪】
  · 配置：%USERPROFILE%\.gssync\config.json（不含 Token）
  · Token：Windows 凭据管理器（目标名 gssync，DPAPI 加密）
  · 云端：你的 GitHub 私有仓库 → Releases → tag "gssync" 下的资产
  · 历史：被覆盖的旧存档会归档在本地 %USERPROFILE%\.gssync\history\

【九、进阶：命令行有同样的功能】
gssync.exe 提供与窗口等价的功能：
  gssync init        初始配置（交互式向导）
  gssync gui         打开图形界面
  gssync push        手动上传（以本机为准）
  gssync pull        手动拉取（以云端为准；旧版本自动归档到本地历史）
  gssync status      查看本地与云端差异
  gssync sync        双向同步一次
        --upload-only    只上传
        --download-only  只下载
        --reset-cloud    以本机为准重建云端（灾难恢复）
  gssync mods-push   上传 MOD（把本机新增/改动的 mod 打包上传云端）
  gssync mods-pull   拉取 MOD（以云端为准下载覆盖本机）
  gssync update      检查并下载更新（--check 只检查不下载）
  gssync version     显示版本号
  gssync watch       守护模式：持续自动同步（游戏运行中只上传不下载）
  gssync history list|restore|clean   本地历史版本管理
  gssync delete <存档名>   删除存档（本机归档后删除，云端同步删除）

【十、常见问题（FAQ）】
  Q: 连不上 GitHub / 一直失败？
  A: 多半是网络问题。请先打开你的代理（全局/加速模式），再重试。程序不会硬连。
  Q: 提示"未找到 Token"？
  A: 设置页 Token 留空会沿用已保存的；若确实没有，请在设置页粘贴 Token 并保存。
  Q: 点【拉取】没反应 / 报"游戏正在运行"？
  A: 请先完全退出游戏再拉取，这是为了防止覆盖正在写入的存档导致坏档。
  Q: 存档到底在哪个目录？
  A: 远行星号：游戏根目录\saves。其它游戏：在设置页【存档目录】里指定。
  Q: 换电脑后存档没过来？
  A: 确认两台电脑用的是同一个仓库和同一个 Token，并在新电脑上点【拉取】。
  Q: Token 会泄露吗？
  A: Token 只存在本机 Windows 凭据管理器（加密），config.json 里没有。
     要把程序给别人时，让对方用自己的 Token，不要直接复制你的 Token。
  Q: 想清空重来？
  A: 删掉 %USERPROFILE%\.gssync 目录，并在 Windows 凭据管理器里删除
     gssync 这条凭据即可。

【十一、安全提示】
  · 不要把 Token 明文发在群里或写进文本；本机存的那份是加密的。
  · 仓库请保持"私有（Private）"，不要改成公开。
  · 存档仓库里就是你的游戏存档，注意不要公开外传。
